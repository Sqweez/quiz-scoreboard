# ТЗ для Codex: Quiz Scoreboard App

## Задача

Нужно реализовать небольшое SPA-приложение для подсчета баллов на квизе.

Стек:

- Nuxt 4
- Vue 3 Composition API
- TypeScript
- Pinia
- Shadcdn + tailwind 4 для стилей
- localStorage для хранения данных
- UI можно сделать простым, без сложной дизайн-системы

Важно: результатом выполнения должны быть изменения в коде, а не текстовое описание. Реализуй рабочее приложение.

---

## Основная идея

Пользователь создает игру-квиз, добавляет команды и раунды, затем во время игры вносит баллы команд по каждому раунду.

Приложение должно автоматически считать:

- сумму баллов команды
- текущее место команды
- промежуточную таблицу результатов
- победителя по правилам тай-брейка

---

## Требования к функционалу

### 1. Создание игры

Нужно сделать страницу создания/настройки игры.

Поля:

- название игры
- список команд
- список раундов

Команды:

- можно добавить команду
- можно удалить команду
- можно переименовать команду

Раунды:

- можно добавить раунд
- можно удалить раунд
- можно переименовать раунд
- можно указать максимальный балл раунда, опционально
- можно указать количество вопросов, опционально

После создания игры пользователь должен попадать на страницу подсчета баллов.

---

### 2. Страница подсчета баллов

Нужно сделать основную таблицу.

Колонки:

- место
- название команды
- баллы по каждому раунду
- сумма баллов

Пример:

| Место | Команда | Раунд 1 | Раунд 2 | Раунд 3 | Итого |
|---|---|---:|---:|---:|---:|
| 1 | Team A | 5 | 7 | 4 | 16 |
| 2 | Team B | 6 | 6 | 4 | 16 |

Баллы по раундам должны редактироваться прямо в таблице через `input type="number"`.

При изменении баллов таблица должна сразу пересчитываться и сортироваться.

---

## Правила сортировки команд

Команды сортируются так:

1. Сначала по общей сумме баллов, больше баллов - выше место.
2. Если сумма одинаковая, сравниваем баллы в последнем раунде.
3. Если в последнем раунде тоже одинаково, сравниваем предпоследний раунд.
4. И так далее до первого раунда.
5. Если все значения одинаковые, порядок можно оставить стабильным.

Пример:

Раунды:

- Round 1
- Round 2
- Round 3

Team A:

- Round 1: 5
- Round 2: 7
- Round 3: 4
- Total: 16

Team B:

- Round 1: 6
- Round 2: 6
- Round 3: 4
- Total: 16

Итог:

- Round 3 одинаковый
- Round 2 у Team A больше
- Team A выше Team B

  id: string

Store должен уметь:

- загружать игру из localStorage
- сохранять игру в localStorage
- обновлять название игры
- добавлять команду
- удалять команду
- переименовывать команду
- добавлять раунд
- удалять раунд
- переименовывать раунд
- обновлять настройки раунда
- обновлять баллы команды за раунд
- считать сумму баллов команды
- возвращать отсортированный список команд
- очищать текущую игру

Ключ localStorage:

```ts
quiz-scoreboard-game
```

## Важная логика

Реализуй отдельную функцию сортировки, например:

```ts
export function sortTeamsByScore(teams: Team[], rounds: Round[]): Team[]
```

Она должна быть покрыта простыми unit-like тестовыми кейсами или хотя бы отдельным dev-примером/комментарием рядом с функцией.

Функция должна:

- не мутировать исходный массив
- учитывать отсутствующие значения как 0
- корректно применять тай-брейк по раундам с конца к началу

## Валидация

Минимальная валидация:

- название игры не пустое
- минимум 1 команда
- минимум 1 раунд
- название команды не пустое
- название раунда не пустое
- баллы не могут быть меньше 0
- если у раунда указан maxScore, баллы не должны быть больше maxScore

При ошибках показывать простые сообщения рядом с формой или через alert, можно без отдельной библиотеки.

---

## Поведение localStorage

- Все изменения должны автоматически сохраняться.
- После перезагрузки страницы игра должна восстановиться.
- Если пользователь удаляет раунд, нужно удалить соответствующие scores у всех команд.
- Если пользователь добавляет новый раунд, у всех команд score по нему должен быть 0.
- Если пользователь добавляет новую команду, scores должны быть созданы для всех существующих раундов со значением 0.
